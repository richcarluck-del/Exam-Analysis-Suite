1.  **全量文件扫描**：扫描项目的所有文件和目录，建立一个完整的项目地图。
2.  **核心应用分析**：深入分析 `app/` 目录下的所有 Python 代码，追踪模块间的导入和调用关系，确定核心业务逻辑文件。

4.  **配置文件审查**：检查所有配置文件（`.conf`, `.yaml`, `requirements.txt` 等），确认其是否仍被使用。
5.  **空目录检查**：找出所有空的文件夹。
