## 🚀 使用方法

### 步骤 1：启动测试页面

在 PowerShell 中执行：

```powershell
cd D:\10739\Exam-Analysis-Suite\preprocessor\preprocessor_test_ui\frontend
npm run dev
```

等待看到：
```
VITE ready in XXX ms
➜  Local: http://localhost:5173/
```

### 步骤 2：打开浏览器

访问：**http://localhost:5173**

### 步骤 3：点击"提示词管理"按钮

在页面**顶部工具栏右侧**，找到 **"提示词管理"** 按钮，点击它。

### 步骤 4：开始管理提示词

- 查看所有提示词列表
- 筛选和搜索
- 点击"编辑"修改提示词
- 保存为新版本
