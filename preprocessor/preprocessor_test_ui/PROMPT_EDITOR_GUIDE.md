# 提示词管理工具使用指南

## 📋 功能概述

提示词管理工具允许你在浏览器中直接查看、编辑和管理数据库中的提示词，无需手动编写 SQL 或 Python 脚本。

## 🚀 快速开始

### 1. 启动后端服务

```bash
cd preprocessor/preprocessor_test_ui
python main.py
```

服务将在 `http://localhost:8000` 启动。

### 2. 安装前端依赖（首次使用）

```bash
cd preprocessor/preprocessor_test_ui/frontend
npm install
```

### 3. 启动前端开发服务器

```bash
cd preprocessor/preprocessor_test_ui/frontend
npm run dev
```

前端将在 `http://localhost:5173` 启动（端口可能不同，查看终端输出）。

### 4. 打开浏览器

访问前端地址（如 `http://localhost:5173`）。

## 🎯 主要功能

### 1. 打开提示词管理界面

- 在测试页面顶部工具栏，点击右上角的 **✏️ 图标** 或 **"提示词管理"** 按钮
- 将在全屏模式下打开提示词管理界面

### 2. 查看提示词列表

界面会显示所有提示词的列表，包含：
- **名称**：提示词的唯一标识符
- **版本**：当前版本号
- **步骤**：所属的 Pipeline 步骤（1-6）
- **类型**：作用对象（exam_paper/answer_sheet/mixed 等）
- **状态**：是否是最新版本
- **更新时间**：最后修改时间
- **操作**：编辑按钮

### 3. 筛选和搜索

使用顶部的筛选栏：
- **步骤筛选**：按 Pipeline 步骤筛选（透视矫正、页面分类等）
- **类别筛选**：按功能类别筛选
- **类型筛选**：按作用对象筛选（试卷、答题纸、混合）
- **搜索框**：输入关键词搜索提示词名称

### 4. 编辑提示词

1. 点击某行的 **"编辑"** 按钮
2. 弹出编辑对话框，显示：
   - 基本信息（名称、版本、步骤、类型）
   - 提示词内容（可编辑文本区域）
   - 字符数统计（实时显示）
   - 变更日志（本次修改说明）
   - 版本历史（最近 5 个版本）

3. 修改提示词内容
4. 填写变更日志（建议填写，便于追踪变更）
5. 点击 **"保存为新版本"**

### 5. 版本管理

- 每次保存都会创建**新版本记录**
- 自动保留所有历史版本
- 新版本号 = 当前版本 + 1（可手动修改）
- 保存后自动标记为"最新"版本
- 原版本仍然保留，不会被覆盖

## 🔧 API 端点

如果需要通过代码访问，可以使用以下 API：

### GET /api/prompts/all
获取所有提示词列表

**参数**：
- `step`: 按步骤筛选（整数）
- `category`: 按类别筛选（字符串）
- `target_type`: 按类型筛选（字符串）
- `search`: 搜索关键词（字符串）

**返回**：提示词列表数组

### GET /api/prompts/{prompt_id}
获取单个提示词详情（包括所有版本历史）

**返回**：提示词信息 + 版本历史数组

### PUT /api/prompts/{prompt_id}
更新提示词（创建新版本）

**参数**：
- `prompt_text`: 新的提示词内容
- `version`: 新版本号
- `status`: 状态（draft|review|published|deprecated）
- `change_log`: 变更日志
- `is_latest`: 是否标记为最新

**返回**：成功/失败信息

### POST /api/prompts
创建新提示词

**参数**：
- `name`: 提示词名称
- `display_name`: 显示名称
- `pipeline_step`: 所属步骤
- `category`: 类别
- `target_type`: 目标类型
- `prompt_text`: 提示词内容

### DELETE /api/prompts/{prompt_id}
软删除提示词（设置 is_active=False）

### GET /api/prompts/stats/summary
获取统计信息

**返回**：
- total_prompts: 总提示词数
- total_versions: 总版本数
- by_step: 按步骤分组统计
- by_type: 按类型分组统计

## ⚠️ 注意事项

1. **权限控制**：目前没有用户认证，任何人都可以编辑提示词。生产环境需要添加权限控制。

2. **操作日志**：目前操作日志记录在数据库中（created_by 字段），但没有独立的审计日志表。

3. **版本回滚**：目前不支持一键回滚，需要手动复制历史版本内容并保存为新版本。

4. **并发编辑**：如果多人同时编辑同一个提示词，后保存的会覆盖先保存的。建议协调好编辑时间。

5. **提示词验证**：
   - 最小长度：10 个字符
   - 版本号必须是正整数
   - 名称必须唯一

## 🐛 故障排除

### 问题 1：无法连接到后端 API

**症状**：前端显示"加载提示词失败"

**解决**：
1. 确认后端服务已启动（`python main.py`）
2. 检查端口是否正确（默认 8000）
3. 检查防火墙设置

### 问题 2：保存失败

**症状**：点击保存后提示错误

**解决**：
1. 检查提示词内容是否太短（至少 10 字符）
2. 检查版本号是否正确
3. 查看后端日志获取详细错误信息

### 问题 3：前端样式错乱

**症状**：页面布局异常或样式不显示

**解决**：
1. 清除浏览器缓存
2. 重新安装前端依赖：`npm install`
3. 重启前端开发服务器

## 📊 数据库表结构

### prompts 表
- id: 主键
- name: 提示词名称（唯一）
- display_name: 显示名称
- description: 描述
- pipeline_step: 所属步骤（1-6）
- category: 类别
- target_type: 目标类型
- scenario: 场景
- version: 当前版本号
- is_latest: 是否最新
- is_active: 是否激活
- created_at: 创建时间
- updated_at: 更新时间

### prompt_versions 表
- id: 主键
- prompt_id: 外键（关联 prompts.id）
- version: 版本号
- prompt_text: 提示词内容
- status: 状态
- change_log: 变更日志
- created_at: 创建时间
- created_by: 创建者
